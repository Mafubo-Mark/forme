# COLMAP 分段与工作流状态修正

本次实际新素材已走到当前视频、标尺和点云驱动的 STL 数字候选，并由云桥接回传；候选仍需尺寸与制造审核。

## 已修正的根因

旧点云工作器按 `images.bin` 文件大小选择稀疏模型。该文件还包含每张图的特征，文件大并不代表注册相机多。一次 81 帧视频断成三个模型后，旧逻辑选中了 20 张相机的片段。

现在读取 COLMAP 二进制文件头中的真实注册相机数量，选择覆盖最多的模型。若不足抽帧数的 80%，自动补做全图匹配和闭环重建，保留首次稀疏结果。修复后若仍不足 70%，暂停并要求复核，不把局部片段当作完整参考。本次实际修复得到 80/81 张已注册相机及 589,210 点；这些数量本身不证明局部表面或佩戴适配。

## 状态显示

- 已完成的 COLMAP 按钮显示“点云已生成”；正在运行时显示实际阶段，避免灰色启动按钮看起来像无法运行。
- 保护套接口根据实际候选返回 `trial_candidate_review` 等状态，移除固定的 `not_connected`。
- 试样 STL 已生成后，云端同步保持“建模／待尺寸、切片与人工审查”，不在每次轮询退回标尺或排队阶段，也不由工作器设置客户 `ready`。
- 候选审查面板会用中文显示内腔超出微调范围、环向覆盖不足、上口净空与疑似薄边等阻塞。

## 本机更新

本机已加载更新。覆盖包新增 `src/forme_backend/model_worker.py`，并更新 `api.py`、`cloud_bridge.py`、`operator/js/app.js`。仅在没有运行中的重建时重载 API 与工作器；保留私有配置和原数据。

本次相关 18 项 Python 测试通过。实际任务还核对了用户确认的 200 mm 标靶、15 个三角化视角、原相机照片叠图、主体裁剪的点云子集来源、封闭网格、PrusaSlicer 导入和云端 STL SHA-256。

## 能力边界

这是可审查数字试样的流程。当前模板微调仍限制在 3 mm 内；本次样本的部分内腔差异超过限制，且存在疑似薄边和不完整的点云环向覆盖，均保留在候选阻塞记录中。切片导入成功不等于实际打印机参数验证或佩戴批准。按当前素材自动生成尺寸正确、可直接佩戴的保护套仍未完成。
