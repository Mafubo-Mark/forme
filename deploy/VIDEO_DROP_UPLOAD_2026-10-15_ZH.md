# 视频拖放上传更新（2026-10-15）

## 发布

从原仓库 Mafubo-Mark/forme 的 main 拉取本次提交，按现有方式发布 dist 静态目录。
涉及 create.html、css/workflow-front.css、js/create-workflow.js、js/i18n.js。
无需修改云端 API 或本地建模服务。若使用 CDN，请刷新以上静态资源缓存。

## 使用

登录后，在创建页面把本机视频拖入上传框，或点击选择。显示已选择文件名后，点击“继续”上传。
支持 MP4、MOV、WebM，最大 512 MB，每次一部影片。拖入会高亮，上传时锁定选择。
英文和繁体中文均有提示。拖至框外不会让浏览器跳转打开视频。

## 验收

本地已核对繁体页面显示，运行 node scripts/test_video_drop.cjs 验证：
拖放文件进入 init / PUT / complete 请求链路；点击选择共用相同状态；格式、大小、多文件检查；上传中阻止替换；错误选择保留此前有效视频。
该测试模拟网络，不代表云端已发布或完成实际浏览器原生拖拽上传验收。

云端发布后：登录创建页面，拖入一个测试视频，核对文件名，点击继续；确认上传成功并进入下一步；再验证点击选择和中英文切换。
