# 后台生产工作流（数字试样候选）

> **2026-10-17 主流程更新**：新订单优先使用点云驱动的全高适配、低上口、下段延长和螺栓避让；无需混元。后台已提供三步入口和持久 scan 队列。操作与 Agent 托管见 [点云主流程](SCAN_WORKFLOW_ZH.md)。下文保留旧概念路线资料，其六视角、混元与 3 mm 微调限制不适用于新入口。

更新：2026-10-06。目标是从用户视频走到**可审查、可导入切片软件的双片保护套试样候选**。这不等于可佩戴成品，也不代表切片参数、侧孔薄边、固定件或实物净空已经验收。

## 每单流程

| 阶段 | 自动/人工 | 当前实现与阻塞 |
| --- | --- | --- |
| 登录、上传、视频质检 | 云端前端/本地 API 与媒体工作器 | 本地接收并哈希、FFprobe 检查、生成复核帧；云端全天候入口由云端同事部署，需把任务同步到本机数据目录或 API。 |
| 拍摄与六视角复核 | 操作员，可用视觉 API 建议 | 确认 200 mm 标靶、正背左右、真实俯视和螺栓侧；缺视角需补拍。 |
| COLMAP | 本地模型工作器 | 点击入队后重建相机和原始点云；输出为无尺度 COLMAP 单位。 |
| 混元输入 | 操作后台 | 六张已确认帧和原视频哈希复核通过后打包。正、左、右、背送给混元 3D 3.1；上口和螺栓图留作结果审查。 |
| 混元生成 | 操作后台提交 + 本地工作器跟进 | 用服务端 `FORME_HUNYUAN_KEY_FILE` 提交；本地混元工作器轮询并归档，后台也可手动查询。每单保留提交尝试与 JobId，避免不确定重试造成重复计费。 |
| 标尺与点云 QA | 操作员 + 几何脚本 | 后台可显示当前 COLMAP 建模帧；在至少三张视角不同的帧中分别点击相同的 A/B 标尺端点，`calibrate_ruler.py` 从该任务的相机重新三角化，要求重投影和基线达标。它只给候选全局尺度。主体分割、区域覆盖和局部表面 QA 仍需复核；旧 `audit_pointcloud.py` 不可套到新单。 |
| 模板与概念形变 | WorkBuddy 提案 + 本地几何脚本 | 每单交接包含模板与生成规则；MCP 仍要求独立坐标注册证据。历史祥云 V2 已有候选，通用 `fit_template.py` 可以做有界形变，但缺可靠配准时拒绝运行。 |
| 候选审核和试样打包 | 操作后台 + 几何 Python | 试验报告和 STL 哈希登记为 `candidate_review.json`；`package_cover_candidate.py` 校验双片水密、单组件及绕向，写出毫米 3MF、两片 STL 和报告。后台可下载 3MF。 |
| 切片与实物试装 | 操作员 | 当前未完成；需按目标打印机/材料核对局部薄边、支撑、成型高度和固定件。佩戴适配必须以实物试装证明。 |

后台 `GET /api/internal/submissions/{id}/production-flow` 返回每一阶段与阻塞项；用户端只收到不含本地文件路径的 `productionProgress`。操作接口均需后台令牌，下载仍使用独立后台的媒体鉴权。

## 本机运行

```sh
cd /Volumes/extra/workspace1/projects/test4/forme-backend
export FORME_HUNYUAN_KEY_FILE=/absolute/path/to/your/SecretKey.csv
FORME_START_WORKERS=1 ./run-local.sh
```

`run-local.sh` 在本机找到几何 Python 时自动设置 `FORME_GEOMETRY_PYTHON`；其他机器请显式设置带 `trimesh`、`numpy`、`pycolmap` 的 Python 解释器路径。混元密钥文件只在本机读取，不上传到前端，也不写入任务清单。启动脚本同时运行媒体、COLMAP、混元工作器和 API；工作器以文件锁防止另一份进程重复处理同一数据目录。建议用系统服务管理器保持本地工作器开机后自动运行。云端登录、上传、查进度的 24 小时服务由云端部署负责，本机可离线排队。

## 已跑通的历史样本

任务 `fa5c0a40-fd4a-474f-80cf-3da92d7af3a8` 已有视频、六视角、COLMAP、混元白模、200 mm 标尺候选尺度、点云 QA、祥云模板候选与数字试样包。新 3MF 位于 `data/cover_tasks/<id>/candidate_print_trial/upper-body-v1/cover_trial_mm.3mf`，约 315 mm 高，双片网格各自水密、单组件且绕向一致；ZIP 与 XML 可解析。它仍有侧孔薄边和装配未知项，目标切片软件尚未验证。

通用标尺脚本用这条历史任务的 29 张已标注照片复算得 141.1745 mm／COLMAP 单位，原记录为 141.2218；相差约 0.034%。这是同一视频和相机数据上的方法对照，不是独立尺寸验证。

## 下一单目前无法自动越过的门槛

1. 标尺端点需要操作员在当前任务的多张建模帧上确认；错误标注即使重投影合理也可能得到错误比例。不能将此尺度当独立实物量测。
2. 主体点云分割、可信区域及模板配准；旧样本脚本有固定路径，不能套到其他用户。缺这一步时通用模板形变继续拒绝执行。
3. 不依赖 WorkBuddy 自报的局部壁厚、自交、上口净空、螺栓避让和目标切片软件检查。

因此这套后台现在能**真实处理任务并生产已具备几何证据的试样包**，但不能把任意新视频一键变成可切片保护套。遇到上述门槛时状态保持待审查，不会伪造成功。
