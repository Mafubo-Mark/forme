# Work Buddy 任务：将现成保护壳模板自动适配真实假肢

## 目标

合作伙伴已经制作了多款**假肢接受腔外侧保护壳模板**。请以这些模板为设计起点，自动选择最合适的款式，并将其内侧贴合面、上口、后侧开口、下缘和螺栓避让调整到与本项目假肢资料尽可能一致。通过自动渲染、几何检查和反复修订，产出可复核的最佳候选。当前阶段是**视觉与数字几何验证**；现有扫描与生成模型不足以证明实物可装配。

本目录 `README.md` 是素材索引，`WORK_BUDDY_TASK.md` 记录了此前从零设计保护壳的要求和失败教训。本任务改用“模板选择 + 受约束变形 + 几何验收”路线。

## 输入素材及可信度

1. **最重要：**`evidence/original_video/IMG_3761.MOV` 与 `evidence/key_frames/`。看清真实上口、筒身轮廓、后侧和螺栓。
2. **几何约束：**`models/test4-cloud-calibrated-mm.ply` 是按 200 mm 标靶校准的点云；有噪声、缺口和遮挡。只在可信区域约束模板，不能把每个散点当成准确表面。
3. **辅助参考：**`models/hunyuan31-v2-aligned-mm.stl` 已对齐到标定点云，仍含 AI 生成误差、鞋和下部多余结构。`blender/base_scene.blend` 中的同源模型使用**另一套本地坐标**，不要直接与点云叠加。
4. **现有保护壳基线：**`baselines/auto_seed/` 和 `baselines/legacy_cover/`。它们提供后侧开口与螺栓避让的结构参考，但尚未验证实体贴合。
5. **合作伙伴模板：**已整理在 `templates/`，以 `templates/catalog.json` 的哈希和来源为准。保留源文件及其修改器或参数历史。优先使用 `.blend`、STEP 或分组清晰的网格；STL 也可试，但需先识别内外表面、开口和装饰区域。

本单没有独立的实物测量；只能从视频中的 200 mm 标定尺推算候选毫米尺度。不得复用旧记录中的 120/80 mm 口述数值。螺栓尺寸未测。先用现有材料完成筛选、概念适配和证据报告，并明确不确定性。

执行前读取 `COVER_GENERATION_POLICY.json`。多款模板和多个公开 STL 未必代表多个独立实物样本；记录来源、许可证和独立样本数。只在点云覆盖可信的区域进行小幅平滑修形。当前保护套的设计意图是**低开口、露出接收器高翻边**；不能仅因翻边高于保护套上口就判定失败，还须检查净空和装配。

## 必须自主完成的工作

### 1. 模板清点、分类和选择

- 每个模板记录文件、单位、坐标朝向、包覆范围、后侧开口方向、上口结构、壁厚、螺栓孔与固定结构是否为独立对象，以及能否参数化编辑。
- 用高度、多个高度截面轮廓、中心线、上口形状和开口位置筛选候选；优先选与真实假肢同类型的模板。留下至少一个备选，不要只凭单张渲染图选款。
- 若多个模板拓扑/设计差异很大，分别适配并比较；不要强行把完全不相似的模板拉变形。

### 2. 坐标对齐和可信区域

- 先统一长度单位、上下方向、前后方向、轴线和高度范围。标定点云与 `hunyuan31-v2-aligned-mm.stl` 共用探索性毫米坐标；Blender 场景另行转换。
- 只取假肢接受腔相关表面，排除鞋、连接件、背景点以及 AI 幻觉几何。结合视频与重建质量为点云区域标注可信/遮挡/硬件突出三类；低可信区域不得被算法强行贴合。
- 用刚性/相似变换建立粗对齐，再作局部非刚性适配。记录实际使用的变换矩阵，避免过去出现的整体倾斜问题。

### 3. 模板变形方式

- **保持模板的设计语义。**将内侧贴合面与外侧装饰、边缘、卡扣、螺栓孔分开控制；先调贴合面，再生成或校验壁厚。外观装饰可随低频形变移动，但不应被点云噪声扭曲。
- 主体形变应平顺、低频，并允许沿高度改变截面与中心线。可使用受约束的非刚性配准、ARAP 或控制笼变形。目标应同时考虑可信点云/轮廓误差、形变平顺性、原模板形状保持和最小净空；不要只追求单一最近点距离。
- 上口保持已确认的低开口设计意图，让接收器高翻边露出；只根据可见边缘和可信几何做局部修正，不能把上口拉成扭曲边。后侧 `+Y` C 形开口需从上到下连通。
- 螺栓避让应在主体拟合后以真实布尔减材或等效建模重建；不能把螺栓误识别成主体鼓包，也不能仅把一个孔随模板整体拉伸后就假定尺寸正确。
- 适配完内表面后再生成/复查壁厚与边缘，不要把 Blender Shrinkwrap 的标称 offset 或 Solidify 的设定值当作最终逐点间隙或壁厚。

### 4. 自动看图、检查和修订

对每个候选至少渲染正面、后面、螺栓侧、斜视及上口局部图。每轮将这些图、实拍关键帧和几何检查结果一起审查，明确写出下一轮改动及原因。可用 Work Buddy 自身的看图能力；若要调用 `automation/agent_loop.py`，先确认它的参数化范围能够表达选中的合作伙伴模板，不能把现有基线脚本直接当作通用模板适配器。

每轮至少记录：

- 模板编号、坐标变换、参数与版本；上口、开口、螺栓侧、下端的四项视觉判断。
- 导出后的网格组件数、边界边数、非流形边数、自交及厚度异常；渲染对象与导出 STL 是否一致。
- 可信扫描区域的表面距离分布、最小净空/穿透区域、低可信区域覆盖比例。明确区分“对生成模型的距离”和“对真实扫描的距离”。
- 与未适配模板及本目录现有基线的同视角对比。某轮变差就回退，而不是机械地增加迭代次数。
- 同源点云的残差改善只作为迭代指标；照片投影、局部壁厚、侧孔薄边、切片预览和实物试装单独记录。未完成项写入每单 `candidate_review.json`，不能把概念候选标为生产放行。

## 完成判定与交付

将结果放入 `output/template_adaptation/`，至少包含：

1. `template_inventory.md`：模板清单、选款依据、被排除模板的原因。
2. `iterations/`：各轮参数、渲染、评估网格、指标和审查记录。
3. `final/`：最佳候选的可编辑 `.blend` 或 CAD 源文件、STL、五视角图、与模板及实拍的对照图。
4. `final/REVIEW.md`：哪些部位明显改善、哪些区域数据不足、是否有穿透或拓扑问题、距离统计及其可信范围。清楚标注 **“概念候选，尚未实物试装验证”**。
5. 若模板缺失、不能编辑，或所有候选均无法满足上口/开口/螺栓要求，给出可复现的阻塞原因和所需的**最小**额外输入；不要提交看似完整却不可用的壳体。

最低几何门槛：保护壳 STL 只有一个连通组件，零边界边、零非流形边；后侧开口连续；上口不遮挡接受腔；螺栓避让是实体孔；无明显自交、局部零厚度或包到鞋。满足这些门槛仍不等于物理适配已证实。

## 可复用的成熟技术

- [Open3D ICP 官方教程](https://www.open3d.org/docs/latest/tutorial/t_pipelines/t_icp_registration.html)：刚性对齐、鲁棒核与配准指标。
- [libigl ARAP 教程](https://libigl.github.io/tutorial/#as-rigid-as-possible)：局部保持形状的网格变形。
- [非刚性模板拟合开源示例](https://github.com/TimoBolkart/TemplateFitting)：模板到扫描的非刚性 ICP；其人脸场景不可直接照搬，需要改成假肢的区域和边界约束。
- [CPD 论文](https://arxiv.org/abs/0905.2635)与 [C++ 实现](https://github.com/gadomski/cpd)：点集非刚性配准的可选基础模块。
- [Blender Shrinkwrap](https://docs.blender.org/UATEST/manual/en/dev/modeling/modifiers/deform/shrinkwrap.html)与 [Solidify](https://docs.blender.org/manual/id/4.5/modeling/modifiers/generate/solidify.html)官方文档：仅作为几何操作与参数说明，最终仍需测量实际输出。
