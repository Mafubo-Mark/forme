# 交给 Work Buddy 的任务

请在本目录内自主完成假肢**外侧保护壳**的 Blender 视觉建模迭代。先读 `README.md` 和 `reports/deepseek_manual_trial_report.md`，再看原视频和六张关键帧。已有场景与自动建模器在 `blender/`、`automation/`。不要让用户重复拍摄或提供一串人工测量值；先充分利用现有素材。

## 设计目标

- 保护壳沿接受腔外形包覆，背侧 `+Y` 保留从上到下连通的 C 形开口；不封住接受腔上口。
- 上口应顺应实拍中的不规则高低边缘，不能是等高圆环，也不能有破碎、交叠或悬空的尖角。
- 中段外表面平顺，没有点云噪声造成的崎岖波纹。
- 螺栓处应有从壳体**实际减去材料**的避让开口；不要把螺栓当成外壳鼓包，也不要添加假螺栓。
- 下端停在接受腔区域，不要包住鞋、连接件或其他生成模型中的下部幻觉结构。
- 保持单一、封闭、可导出的保护壳网格。外观、布尔运算后的 STL 和 `.blend` 评估结果必须一致。

## 自主循环

1. 以 `baselines/auto_seed/` 为基线，观察四视角、实拍与 `metrics.json`。必要时打开 `blender/base_scene.blend` 检视三维对象。
2. 修改 `automation/seed_spec.json` 的副本，使用 `automation/build_iteration.py` 调用 Blender 生成新版本。可先用现有参数范围迭代；若参数化能力不足，允许改进确定性建模器，但每次都运行几何和视觉验收。不要让语言模型直接生成并执行不受约束的整段 Blender Python；过去两轮失败记录已证明风险。
3. 每轮检查四视角的上口、中段、后侧开口、螺栓侧和下端，再检查导出 STL 的高度、连通组件数、边界边数与非流形边数。保存每轮 `spec.json`、四视图、`metrics.json`、`shell.stl`、`review.blend`，并记录保留或否决该轮的原因。
4. 对照原视频。Hunyuan STL 是 AI 生成的外形参考，不能把其皱褶、鞋或不存在的五金件当作实物。点云有缺口与噪声；只有在坐标变换正确后，才用点云做定量距离比较。
5. 找到更好的方案后，把最终候选、四视角拼图、关键指标及仍未验证的物理风险放到 `output/final/`，并写 `output/final/REVIEW.md` 说明相对基线改善了什么。若无法达到要求，保留最佳版本和失败原因，不要把视觉概念称为可试装成品。

## 已知技术约束

- `blender/base_scene.blend` 中的参考物体包含完整生成模型：约 `z=-252.5…371 mm`。保护壳基线约 `z=18.1…331.5 mm`。直接按整个参考模型的 z 范围造壳会错误包住鞋。
- `models/hunyuan31-v2-aligned-mm.stl` 与 `models/test4-cloud-calibrated-mm.ply` 共用探索性毫米坐标系；它们**不直接共用** Blender 场景的本地坐标系。
- 基线 3 mm 壁厚、标称 8 mm Shrinkwrap 偏移仅供造型。平滑和上沿修改会改变局部间隙。已有螺栓避让器尺寸为概念值，未经实测。
- 用户此前报告：简单圆柱壳、点云噪声鼓包、倾斜轴线、固定件误识别、过短壳及上口处理失败均不可接受。

## 完成定义

以视频和四视图能说明设计合理；最终评估 STL 有且仅有一个连通组件、零边界边、零非流形边；提供可编辑 `.blend`、STL、参数与复核记录。**不要宣称实际贴合、可打印试装或螺栓净空已经验证。**
