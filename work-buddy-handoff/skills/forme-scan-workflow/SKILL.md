# Forme 点云保护套工作流

目标：处理指定真实任务，交付可审查的双片毫米 STL 与螺栓区域试配件。默认路线为 `scanfit-v5-20261017`，不调用混元或视觉付费 API。首个支持的生产样式是 06 通风模板。

## 定位与接手

项目通常为 `/Volumes/extra/workspace1/projects/test4`；迁移后以实际 `forme-backend` 和 `work-buddy-handoff` 同级位置为准。若本 skill 安装在全局 skills 目录，先找项目，不能按全局目录猜后端路径。

读取 [接口与接手](references/operation.md)。先列真实订单、核对任务号和源视频哈希，读 `get_scan_workflow` 或 `GET /api/internal/submissions/{id}/scan-workflow`。状态为 queued/running 时观察进度，ready 时校验报告与文件，failed 时先读该候选 `worker.log` 和 `logs/`，不重复上传或创建订单。

没有 MCP 时使用后端的 `scripts/scan_workflow_cli.py`。运行时位置与依赖见接口说明。不要在聊天、日志或命令回显中暴露密钥。

## 连续推进

1. 检查当前视频可见纹理、环绕重叠、上口、螺栓和下方连接段。标尺实际长度必须来自用户或可追溯物理规格；已获确认不重复询问。质量通过后启动本单 COLMAP，保留其原始相机和点云。
2. 按 [几何准备](references/geometry.md) 完成本单标尺、主体裁剪、刚体定轴、前后方向、上缘、下缘和螺栓轴线；用后端 `prepare_scan_reference.py` 封存复核卡。输入不足时明确所缺视角或物理信息，继续不依赖缺项的工作。
3. 根据本次授权处理复核。用户已明确委托 agent 完成本单数字试样，且标尺实长、方向、主体与孔位证据充分时，可以调用 approve；需要用户确认的实际长度／不确定方向仍应等待。批准只绑定这组输入，不批准佩戴或生产。
4. 调用 `queue_scan_cover` 或 run 接口，等待持久队列完成。检查最终 `release_review.json`、前后片 STL、组合 STL、孔道／干涉报告和预览。默认交付 STL 包，不把 3MF 当作唯一交付。
5. 向用户报告文件、所用源视频、尺度依据、未验证项和下一步。实物试戴反馈仅记录到对应候选的文件哈希；不自动套给重建、重导出或下一位使用者。

## 避免已发生的错误

- 成功参考为 IMG_3986 新纹理视频的 V5。其 60 mm 延长、38 mm 螺栓孔、200 mm 标尺及坐标是该案例参数，不是每单默认测量值。读 [成功案例与约束](references/accepted-method.md) 后再解释历史经验。
- 不用混元形状决定内腔，不以旧 3 mm 微调上限或冻结模板上口代替全高度点云拟合。新路线和旧概念入口是两个不同生成器。
- 先用当前视频的相机恢复尺度与方向，再比较相同高度的点云与壳体。不能用背景点数、重投影误差或水密性单独宣称贴合。
- 壳体覆盖螺栓以下的真实连接段，避开踝部活动／鞋；螺栓作为独立避让通道，不能把凸起平滑成后侧鼓包。上口按当前可见边界裁低，露出高翻边。
- 输出被改、相机模型变、关键证据缺失时停止生成，重新准备复核；不要伪造审批文件、物理测量、试戴或切片记录。
- 同一输入最多两次生成尝试；重复失败先报告原因并修证据，不无限循环调参数。不同版本保留原件，不覆盖已试戴 STL。
- 托管范围是本单几何处理与数字候选交付。发布给客户、打印机开机／实体打印、云部署、外发患者资料仍按用户已有授权范围办理。
