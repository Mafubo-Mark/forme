# 合作伙伴保护套模板库

源文件位于工作区 `modols/`（沿用来件拼写），这里是整理后的工作副本。运行 `python3 automation/template_library.py register` 可重建 `catalog.json`；压缩包 SHA-256、逐件 STL SHA-256 和三角面数记录在清单中。原始压缩包不被改动。

| ID | 样式 | 固定方式 | 可编辑源文件 | 当前用途 |
|---|---|---|---|---|
| 01 | 祥云 | 旋转压片扣 | 无，仅 STL | 概念筛选 |
| 02 | 蜂巢 | M2.5 耳座螺钉 | 无，仅 STL | 概念筛选 |
| 03 | 流线 | 耳座和插销 | 无，仅 STL | 概念筛选，插销同轴需复核 |
| 04 | 竹影 | 穿绳束合 | 无，仅 STL | 首个受限形变候选 |
| 05 | 鳞羽 | 磁吸、定位销、保险螺钉 | 无，仅 STL | 概念筛选 |
| 06 | 通风 | 独立 ABS 弹性钩扣 | 无，仅 STL | 概念筛选，钩扣寿命需复核 |
| 05-magnetic | 鳞羽内嵌磁吸 | 隐藏磁铁与防丢绳 | **有 `.blend`** | 结构编辑优先；保持力尚未验证 |

`unidentified/` 收纳独立的 `前壳.stl` 与 `后壳.stl`。它们与内嵌磁吸包的文件尺寸和面数不同，不能直接当作包内版本或成套最终件。

七套来源均声称以 121 mm 尺寸校准、名义径向净空 1.5 mm、高约 315.25 mm；这些是来件元数据，不是我们的实测。已独立核对二进制 STL 长度和三角面数。模板 Z 范围为 0–315.25 mm；项目现有上段分割网格约为 134–366 mm，不能按坐标原样叠合。未完成坐标注册、穿透/壁厚/固定力检查和试装前，任何模板都不是可交付的实用保护套。
